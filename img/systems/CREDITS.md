# System icons

The console and controller icons in this folder come from the "Retrosystem" XMB theme in
[libretro/retroarch-assets](https://github.com/libretro/retroarch-assets) (`src/xmb/retrosystem`),
licensed under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

Changes: editor metadata removed, files renamed, and the Super Nintendo controller's face buttons
recoloured to the European / Super Famicom red, yellow, green and blue.

Game box art and screenshots are loaded at runtime from the libretro thumbnail server
(thumbnails.libretro.com) and are not part of this repository.
